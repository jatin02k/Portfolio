# Jatin Kumar portfolio

An editorial portfolio for AI workflow automation and custom software projects, built with Next.js App Router, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Before deployment, set `NEXT_PUBLIC_SITE_URL` to the site's public origin. Profile and project links are configured in `app/page.tsx`.

To create a production build, run `npm run build`, then `npm start`.
